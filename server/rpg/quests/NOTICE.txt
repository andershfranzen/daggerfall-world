Third-party notices for server/rpg/quests/, server/rpg/quests.js and client/gameplay/quests.js
==========================================================================================

No quest scripts, quest text or other Bethesda content is distributed here. At run time
the server reads quests from files the operator supplies:

  * classic QRC (text) and QBN (compiled logic) files from their own ARENA2 directory
    (ctx.dataPath), and
  * quest scripts in the Daggerfall Unity text format from a directory the operator
    points at (DFW_QUEST_SCRIPTS / config.questScripts), e.g. their own copy of
    Daggerfall Unity's StreamingAssets/Quests.

The task semantics in engine.js and actions.js (task trigger/rearm rules, the
`when ... and/or` evaluator, action patterns and their behaviour), the script parser in
script.js, the clock option rules, the quest gold formula and the small symbol tables
in tables.js (foe, place-type, item-class, static-message and global-variable names) are
adapted from Daggerfall Unity's Game/Questing code and StreamingAssets/Tables. Parts of
the parser follow the JavaScript port in dfjs (MIT). Tables marked "adapted from
Template 1.11 by Donald Tipton" in Daggerfall Unity keep that attribution.

The classic QRC and QBN binary layouts in qrc.js and qbn.js were worked out by reading
the operator's own files and are this project's work.
